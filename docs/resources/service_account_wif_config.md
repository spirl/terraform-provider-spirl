# spirl_service_account_wif_config (Resource)

Manages the Workload Identity Federation (WIF) configuration for a service account. Binds a `spirl_org_wif_issuer` to a service account and defines the token claims required for authentication.

Either `claims` must be non-empty or `allow_any_bearer` must be `true`.

-> **Note:** Each service account can have at most one WIF config. The `service_account_id` attribute acts as the upsert key. Changing `service_account_id` will destroy and recreate the resource.

## Example Usage

```terraform
resource "spirl_org_wif_issuer" "github" {
  name       = "github-actions"
  issuer_url = "https://token.actions.githubusercontent.com"
}

# Authenticate a specific repository branch
resource "spirl_service_account_wif_config" "deployer" {
  service_account_id  = "sa-1234567890"
  org_wif_issuer_name = spirl_org_wif_issuer.github.name

  claims = {
    sub = "repo:my-org/my-repo:ref:refs/heads/main"
    aud = "spirl"
  }
}

resource "spirl_org_wif_issuer" "jenkins" {
  name       = "jenkins"
  issuer_url = "https://jenkins.internal.example.com"
}

# Accept any bearer from a self-hosted issuer
resource "spirl_service_account_wif_config" "internal_sa" {
  service_account_id  = "sa-0987654321"
  org_wif_issuer_name = spirl_org_wif_issuer.jenkins.name
  allow_any_bearer    = true
}
```

## Schema

### Required

- `org_wif_issuer_name` (String) The name of the `spirl_org_wif_issuer` to use for token validation.
- `service_account_id` (String) The ID of the service account (`sa-*`). Changing this destroys and recreates the resource.

### Optional

- `allow_any_bearer` (Boolean) When `true`, any token issued by the issuer is accepted without claim matching. Must be set explicitly when `claims` is empty.
- `claims` (Map of String) Token claims to validate (e.g. `sub`, `aud`). Required unless `allow_any_bearer` is `true`.

### Read-Only

- `id` (String) The ID of the WIF config (`sawif-*`).

## Import

#!/bin/bash
