# spirl_org_wif_issuer (Resource)

Manages a Workload Identity Federation (WIF) issuer at the organization level. WIF issuers define trusted OIDC token issuers that service accounts can authenticate against using `spirl_service_account_wif_config`.

At most one key source (`oidc_uri`, `jwks_url`, `jwks`, `jwks_pem`) may be set. If none is set, the issuer URL is used for OIDC discovery.

-> **Note:** The `name` attribute acts as the upsert key. Changing `name` will destroy and recreate the resource.

~> **Warning:** The `jwks_pem` value cannot be retrieved from the API after it is written. If you import an issuer that uses `jwks_pem`, you must add the value to your configuration and re-apply to resolve the state diff.

## Example Usage

```terraform
# GitHub Actions issuer using OIDC auto-discovery
resource "spirl_org_wif_issuer" "github" {
  name       = "github-actions"
  issuer_url = "https://token.actions.githubusercontent.com"
}

# Custom issuer with an explicit JWKS URL
resource "spirl_org_wif_issuer" "custom" {
  name       = "my-custom-issuer"
  issuer_url = "https://idp.example.com"
  jwks_url   = "https://idp.example.com/.well-known/jwks.json"
}

# Issuer with PEM-encoded public key (sensitive, write-only)
resource "spirl_org_wif_issuer" "internal" {
  name       = "internal-issuer"
  issuer_url = "https://internal-idp.example.com"
  jwks_pem   = file("path/to/public-key.pem")
}
```

## Schema

### Required

- `issuer_url` (String) The HTTPS URL of the OIDC issuer (must match the `iss` claim in tokens).
- `name` (String) The name of the WIF issuer. Used as the upsert key — changing it destroys and recreates the resource.

### Optional

- `jwks` (String) Inline JWKS JSON document. Mutually exclusive with `oidc_uri`, `jwks_url`, and `jwks_pem`. Stored in Terraform state in plaintext — prefer `jwks_pem` if the document contains sensitive material.
- `jwks_pem` (String, Sensitive) PEM-encoded public key(s). Sensitive — the API does not return this value after write. Mutually exclusive with `oidc_uri`, `jwks_url`, and `jwks`.
- `jwks_url` (String) URL of the JWKS endpoint. Mutually exclusive with `oidc_uri`, `jwks`, and `jwks_pem`.
- `oidc_uri` (String) Override URL for OIDC discovery (`.well-known/openid-configuration`). Mutually exclusive with `jwks_url`, `jwks`, and `jwks_pem`.

### Read-Only

- `created_at` (String) RFC3339 timestamp of when the WIF issuer was created.
- `id` (String) The ID of the WIF issuer (`owi-*`).
- `updated_at` (String) RFC3339 timestamp of when the WIF issuer was last updated.

## Import

```shell
#!/bin/bash

# WIF issuers are imported using their name
terraform import spirl_org_wif_issuer.github github-actions
```
